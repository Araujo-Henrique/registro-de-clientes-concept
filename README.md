# Sistema de registro de Clientes Concept Vistos

## Problema a ser solucionado
Os registros da empresa sao mantidos todos nas planilhas do Google Sheets. A intencao desse projeto e tirar a dependencia do Google Sheets e permitir que a empresa se torne mais independente tendo o seu proprio sistema de registros atraves de uma construcao de uma aplicacao backend.
## Objetivo
Eventualmente esse sistema podera ficar mais robusto e ter visualizacao tambem para os clientes, mas o objetivo principal no momento e criar um sistema de registro, edicao e remocao de clientes com acompanhamento dos processos em tempo real. Em outras palavras um Dashboard. Sera desenvolvido uma API para gerenciar a entrada e tratamento dos dados utilizando Python, FastAPI e posteriormente PostgreSQL
## Primeira versao do projeto
A primeira versao trara as seguintes funcionalidades:
- Cadastro de clientes
- COnsulta de clientes
- Atualizacao
- Exclusao
- Busca e filtros
## Aprendizados
Nessa primeira etapa os conceitos estudados e praticados serao:
- Python
- HTTPS
- APIs REST
- FastAPI
- SQL
